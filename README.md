# TrackCleaner — releases

Download builds of **TrackCleaner**, a Mac app that makes radio-clean versions of songs:
it separates the vocal from the music, finds the profanity, and ducks *only the vocal*
over each word while the music keeps playing — then hands you a waveform and a transcript
so you can check every censor by ear.

### ⭢ [Download the latest release](https://github.com/elDoof/trackcleaner-releases/releases/latest)

A nicer download page lives at
**<https://eldoof.github.io/trackcleaner-releases/>**.

## You need an activation key

TrackCleaner is licensed software and stays locked until a key is entered. Keys are issued
to individual people at BPM Supreme — **ask your team lead** if you have not been sent one.

## Installing

1. Download the `.dmg` from the latest release.
2. Open it and drag **TrackCleaner** to your Applications folder.
3. Launch it and paste in your activation key.

It opens like any other Mac app: the build is signed and notarized by Apple. If macOS
warns you about it, the download is incomplete — get a fresh copy rather than working
around the warning.

The first launch needs an internet connection and a few minutes while it downloads the
audio models it uses, with progress shown. After that it works offline, and the first song
you clean is slower than the rest while the models warm up.

## Requirements

- An **Apple Silicon** Mac (M1 or newer). Intel Macs are not supported.
- **macOS 12** Monterey or later.
- About **5 GB** free disk space for the audio models.

## About this repository

This repo holds **published builds and the download page only**. TrackCleaner's source is
